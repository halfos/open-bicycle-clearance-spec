# BSD and common size names

BSD is the bead-seat diameter in millimetres as used by ETRTO / ISO 5775.
Always publish BSD exactly; do not round a French or inch name into a nearby
standard size. Inch names are approximate marketing labels, not dimensions.

French letters describe nominal outside diameter families and are particularly
easy to confuse: 700a/b/c correspond to 642/635/622 mm; 650a/b/c correspond to
590/584/571 mm. The letters do not indicate interchangeable rims.

For display only, approximate outside diameter is `BSD + 1.9 × measured width`.
This is not a substitute for measuring the tyre or checking frame clearance.
