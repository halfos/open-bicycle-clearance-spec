# Measurement guide

Record frame identity, size, wheel/BSD, tyre measured width, rim internal width,
fender, axle position, suspension position, method, instruments, resolution,
date, repeats, uncertainty, and photos. Measure the worst-case permitted axle
and suspension positions.

## Wheel clearance methods

1. **Tyre on, drill bits as feeler gauges.** Fit the actual wheel and intended
   tyre. Sweep the wheel and check both sides, crown, bridges, and yoke with
   smooth drill-bit shanks. Record the smallest gap at each relevant obstacle.
2. **Bare rim with calipers.** Measure frame opening and wheel/rim alignment.
   Flip the wheel and repeat to cancel wheel dish error; report the lower
   clearance, not the average.
3. **Tyre-section fit gauges on an axle-pivot arm.** Lock the arm at an exact
   BSD mark, install the width gauge, sweep a full turn, and find the minimum
   gap with drill bits. Repeat for each BSD and width. A gauge must use the
   same reference tyre definition as this specification.
4. **Contour gauge.** Use retract-only pins so they cannot force or damage
   frame material. Sweep the complete arc, lock the pin positions, then
   photograph before removing the gauge.
5. **3D scan.** Align the scan to the axle centre and wheel plane; preserve
   scale and record scanner resolution and alignment uncertainty.
6. **Manufacturer CAD.** Use the exact production frame geometry and worst-case
   tolerances, axle adjustment, and suspension travel. Identify CAD revision.

## Chainring method

Measure frame material outboard of the BB shell around the BB axis. Check each
supported chainline, ring tooth count, and declared 2x combination using the
reference envelope in SPEC.md. Include the front derailleur and tyre constraint
where applicable; do not infer a 2x fit from a 1x result.

## Indicative method uncertainty

These are reporting guides, not guarantees; contributors must state actual
instrument uncertainty.

| Method | Typical resolution / uncertainty |
|---|---|
| Tyre plus drill-bit shanks | about 1 mm; tyre and operator dominate |
| Bare rim with calipers | about 0.1–0.5 mm; alignment dominates |
| Pivot arm fit gauge | about 0.5–1 mm including gauge tolerance |
| Retracting contour gauge | about 1–2 mm including pin pitch |
| 3D scan | scanner/alignment dependent; report both |
| Manufacturer CAD | tolerance-stack dependent; report assumptions |

## Photo requirements

Include a full-frame identification view, the wheel and tyre label, a ruler or
calibration scale, and close-ups of each binding point. Show the gauge both
before and after measurement when used. Photos should be sharp, in focus, and
include the relevant axle, centre plane, and direction of measurement. Remove
location metadata before public submission.
