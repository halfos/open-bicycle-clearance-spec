# Rationale

## Why “maximum tyre” is ambiguous

A maximum without a BSD, measured width, rim internal width, fender condition,
or clearance margin does not identify a reproducible fit. Nominal labels are
not measurements: two tyres marked identically can differ, and a tyre changes
width with rim width and age. BSD must also remain exact; nearby values such as
571, 584, and 590 mm cannot be rounded together.

OBCS therefore reports measured width against exact BSD, separates fender/no
fender conditions, and specifies a minimum gap and a named margin class.

## Tyre room versus chainring room

The chainstay yoke occupies the same constrained region that limits a wide
rear tyre. Moving the drive-side stay outward can create tyre space, but may
reduce chainring clearance; moving it inward can do the reverse. A single
“maximum tyre” number cannot describe that trade-off. The wheel profile and
BB-axis chainring profile report these independently, with chainline and setup
conditions.
